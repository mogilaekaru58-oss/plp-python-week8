PLP Python Week 8: Personal Mini-Toolkit

What the Toolkit Does

The Personal Mini-Toolkit contains three useful tools: a to-do list manager, a simple calculator, and an even-or-odd number checker. The user selects a tool from a repeating menu and can return to the menu until choosing Quit. The program uses functions, loops, conditionals, a changing list, input validation, and f-strings.

How to Run

1. Install Python 3.
2. Open a terminal in the project folder.
3. Run the program with:

python toolkit.py

Reflection

The hardest part was organizing the tools so they work together through the main menu. Testing helped me understand how each tool returns to the menu and how the Quit option ends the program. I learned how to add, display, and remove items from a Python list. I also practiced using loops, conditionals, functions, and f-strings. One important challenge was entering choices in the correct menu and checking that invalid choices were handled properly. With one more week, I would add a feature to save tasks to a file so they remain available after the program closes.
